# Contributing to RTE

Thank you for considering contributing to RTE! Together, we can make this project more robust and helpful for everyone. Below, you'll find guidelines for contributing effectively.

## Getting Started

1. Fork the repository: Click on the "Fork" button at the top right of the GitHub page.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/your-username/rte.git
   ```
3. Navigate to the project directory:
   ```bash
   cd rte
   ```
4. Install dependencies:
   ```bash
   npm install
   ```

## Development Workflow

### Running the Project
- To test CLI commands, use:
  ```bash
  npm run dev
  ```
- Explore examples:
  ```bash
  rte dev examples/basic.tsx
  ```

### Branching
- Create a new branch for your changes:
  ```bash
  git checkout -b feature/your-feature-name
  ```
- Keep changes focused and scoped.

## Code Quality

### Linting
- Run lint checks before committing:
  ```bash
  npm run lint
  ```

### Testing
- The testing suite verifies the project integrity:
  ```bash
  npm test
  ```
- Add tests for any new features or bug fixes.

## Submitting Changes

1. Stage and commit your changes:
   ```bash
   git add .
   git commit -m "Add description of changes"
   ```
2. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
3. Open a pull request:
   - Go to the repository on GitHub.
   - Click: **Pull Requests** > **New Pull Request**.

Please ensure your branch is up-to-date with the `main` branch before submitting the pull request.

## Reporting Issues
- Check if the issue already exists in the [issues section](https://github.com/Nom-nom-hub/rte/issues).
- Provide clear and descriptive details of the problem.

## Feedback and Support
We value any feedback or suggestions. Feel free to open discussions or submit feature requests.

Thank you for your efforts and dedication! 🚀
