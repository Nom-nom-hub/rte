// Features

🎯

Deterministic rendering

Same input → same output. Every render is reproducible.

⏪

Time-travel replay

Walk through render history frame-by-frame.

🔍

CLI diff & debugging

Compare sessions to find divergence instantly.

📊

Performance benchmarking

Measure render times, memory, FPS in terminal.

🎬

Frame-based execution

Capture every render state as a snapshot.

// Commands

rte dev <file>
Run with debug panel
rte replay <file>
Replay session
rte diff <a> <b>
Compare sessions
rte benchmark
Run benchmarks

// Why this exists

Built for debugging and understanding React-style UI execution in the terminal with deterministic replay and causality tracking.
